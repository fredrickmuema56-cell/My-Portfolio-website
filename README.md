# Fredrick Muema Musyoki — Reimagined Portfolio

This version uses the original portfolio as a **content/context source**, not as a visual template.

## Direction
- Full-bleed photographic environments instead of a black site-wide canvas.
- Cyan, teal, warm beige, gold and small coral accents; purple intentionally removed.
- Real profile photography from the original portfolio is retained for the person-focused imagery.
- Page-specific environments: savanna, mountain lake, ocean, coast and a dedicated SCI visual atmosphere.
- Transparent editorial surfaces sit above the photography so the background remains part of the experience.
- A lightweight Three.js enhancement adds floating geometry, rings, particles and depth without making the content dependent on WebGL.
- The footer is a full navigation/contact/identity section rather than a generic copyright strip.

## Content retained
The site keeps the original portfolio's context and substantive information across About, Skills, Projects/SCI, Experience, Credentials, Gallery, CV and Contact.

## External visual sources
Some page backgrounds use photographs hosted by Unsplash through `images.unsplash.com`. The original personal/profile photographs remain local in `images/profile/`.

## Deployment
Static HTML/CSS/JS. Suitable for GitHub Pages. No build step is required.
