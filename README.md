# Fredrick Musyoki — Personal Portfolio

A multi-page personal portfolio built with **HTML5, CSS3, and vanilla JavaScript only**.

## Visual direction

The second pass pushes the design toward a more personal, charismatic and dimensional identity:

- large formal portrait hero with layered depth
- first-person copy written as Fredrick speaking directly
- restrained cyan/red neon accents
- CSS perspective and 3D-style photo layering
- floating glass information cards
- subtle scanline, glow and floating animations
- formal clothing photos used more prominently across Home, About and Gallery
- responsive mobile layouts
- reduced-motion support

## Run locally

1. Unzip the project.
2. Open `index.html` in a browser, or serve the folder with any simple static server.
3. All navigation, gallery previews, certificate previews and local interactions are self-contained.
